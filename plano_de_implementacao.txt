1. OBJETIVO GERAL DO SISTEMA
--------------------------------------------------------------------------------
Desenvolver e aprimorar um sistema visual e interativo de gestão de almoxarifado
e controle de estoque 2D para o ambiente educacional e operacional do SENAI.
O sistema permite:
- Visualizar em planta baixa 2D as 15 posições físicas de armazenagem (estantes,
  armários, gaveteiros, ilhas e paletes);
- Cadastrar produtos por categorias padronizadas e regras específicas;
- Controlar lotes, validades (com alertas por cores), estoque mínimo e máximo;
- Importar e exportar catálogos e inventários via planilhas Excel (.xlsx);
- Persistir o estado completo de forma relacional no MySQL, permitindo
  que múltiplos computadores, abas e usuários acessem exatamente o mesmo estoque
  em qualquer provedor de hospedagem web (cPanel, Hostinger, AWS ou local no Laragon).


2. ARQUITETURA E TECNOLOGIAS UTILIZADAS
--------------------------------------------------------------------------------
- Frontend: Single-File Application (index.html / index.php) de alta performance
- Estilização & UI: Tailwind CSS (via CDN) + Lucide Icons + Identidade Visual SENAI
- Manipulação de Planilhas: SheetJS / xlsx (via CDN)
- Backend API: PHP 8.x nativo (api.php) com endpoints RESTful JSON
- Banco de Dados: MySQL (database.sql) com tabelas relacionais indexadas
- Configuração de Conexão: config.php (PDO com variáveis de ambiente ou credenciais padrão)
- Servidor Web: Apache do Laragon, Nginx, PHP Built-in Server ou qualquer hospedagem cPanel

4. COMO CONTINUAR O PROCESSO EM OUTRA MÁQUINA (PASSO A PASSO)
--------------------------------------------------------------------------------
Para transferir e rodar este projeto em outro computador, siga os passos abaixo:

PASSO 1: Copiar os Arquivos
Copie toda a pasta do projeto para a nova máquina:
- Arquivos essenciais:
  * index.html (aplicação completa)
  * server.ps1 (script para rodar servidor local no Windows, ajustado dinamicamente para $PSScriptRoot)
  * firestore.rules (regras de segurança para manter acesso permanente no Console do Firebase)
  * plano_de_implementacao.txt (este documento de referência)

PASSO 2: Iniciar o Servidor Local
Na nova máquina, abra um terminal (PowerShell, Prompt ou bash) na pasta e execute:
- No Windows (PowerShell):
  powershell -ExecutionPolicy Bypass -File .\server.ps1
- OU se tiver Python instalado:
  python -m http.server 8080
- OU no VS Code:
  Basta clicar com botão direito no index.html -> "Open with Live Server"

PASSO 3: Abrir no Navegador
Acesse: http://localhost:8080/

PASSO 4: Validação da Nuvem
Como as credenciais do Firebase Firestore já estão salvas no 'index.html',
o sistema se conectará automaticamente à nuvem. O indicador no canto superior
deverá mostrar "Banco de Dados Salvo" (verde), carregando todos os produtos e
posições cadastrados anteriormente de forma imediata!
